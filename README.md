# Lab 6 - Чат-бот и Обфускатор

Этот репозиторий содержит два основных компонента:

## 1. Чат-бот (chatbot.py)

Простой интерактивный чат-бот на Python, который может поддерживать разговор и помогать пользователям.

### Возможности чат-бота:

- 🤖 Поддержка разговора на русском и английском языках
- ⏰ Показывает текущее время
- 😄 Рассказывает анекдоты
- 💬 Отвечает на вопросы об обфускаторе
- 📝 Сохраняет историю разговора
- 🎯 Распознаёт различные паттерны в сообщениях

### Запуск чат-бота:

```bash
python3 chatbot.py
```

### Команды чат-бота:

- `выход` или `exit` - завершить разговор
- `история` или `history` - показать историю разговора
- `очистить` или `clear` - очистить историю
- `привет` - поздороваться
- `что ты умеешь` или `помощь` - узнать возможности бота
- `время` - узнать текущее время
- `анекдот` - услышать шутку
- `обфускатор` - узнать об обфускаторе

### Пример использования:

```
Вы: привет
LabBot: Привет! Я LabBot, чем могу помочь?

Вы: что ты умеешь?
LabBot: Я могу:
- Отвечать на вопросы
- Помогать с обфускатором
- Просто поболтать
- Показать время
- Рассказать анекдот

Вы: время
LabBot: Сейчас 21:00:25

Вы: выход
LabBot: До свидания! Удачи в учёбе! 👋
```

## 2. Обфускатор кода (obSKUFATOR.py)

Инструмент для обфускации C кода, который усложняет его чтение и понимание.

### Возможности обфускатора:

- Удаление комментариев
- Удаление лишних пробелов и табуляций
- Удаление лишних переносов строк
- Сжатие кода в одну строку
- Добавление случайных функций
- Добавление случайных переменных
- Добавление случайных условных конструкций

### Настройка:

Отредактируйте файл `config.json` для настройки параметров обфускации:

```json
{
  "remove_comments": true,
  "remove_spaces": true,
  "remove_tabs": true,
  "remove_newlines": true,
  "collapse_all_to_one_line": true,
  "add_trash_functions": true,
  "add_trash_variables": true,
  "add_trash_ifs": true
}
```

### Использование обфускатора:

```python
from obSKUFATOR import obfuscate, load_config

config = load_config()
with open('input.c', 'r') as infile:
    with open('output.c', 'w') as outfile:
        obfuscate(infile, outfile, config)
```

## Файлы проекта:

- `chatbot.py` - чат-бот
- `obSKUFATOR.py` - обфускатор кода
- `config.json` - конфигурация обфускатора
- `names_for_obfuskator.txt` - список имён для генерации случайных переменных
- `newpassword.c` - пример программы проверки пароля
- `passwordnew.txt` - файл с паролем
